# **Amazed**

## **Description**
The goal of the Amazed is to move all robots in a maze from the entrance to the exit.

## **Usage**
To compile the project, use `make re` in a terminal.
Then execute the program using `./amazed < [input file]`.
You can also use the the `./gen/laby_gen.pl` to generate the input file.
