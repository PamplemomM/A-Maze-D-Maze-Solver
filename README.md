# **A-maze-d**

## **Description**
The goal of the A-Maze-d project is to move a set of robots through a maze from the entrance to the exit.

## **Usage**
To compile the project, use `make re` in a terminal.
Then execute the program using `./amazed < [input file]`.
You can also use the `./gen/laby_gen.pl` to generate the input file.
